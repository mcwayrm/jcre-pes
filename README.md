# JCRE Special Issue Replication Starter Repository

This repository is the starting point for replicators working on the Journal of Comments and Replications in Economics (JCRE) special issue on Payments for Ecosystem Services.

## How Replicators Should Proceed

1. Read the replicator guidance first.
   - Open [replicator-instructions.docx](replicator-instructions.docx).
2. Identify the paper or assignment you are replicating.
   - Use [special-issue-articles-pes.xlsx](special-issue-articles-pes.xlsx).
3. Review examples before drafting your own materials.
   - See [replication-example.pdf](replication-example.pdf) for a replication write-up example.
   - See [PAP-example.pdf](PAP-example.pdf) for a pre-analysis plan example.
4. Prepare your replication package using the template.
   - Start from [replication-template.docx](replication-template.docx).
5. Record and maintain replication metadata.
   - Update [replication-metadata.xlsx](replication-metadata.xlsx) with required fields and progress details.
6. Final checks before submission.
   - Confirm your documentation is complete and follows the formatting and content rules in [replicator-instructions.docx](replicator-instructions.docx).

## Repository File Guide

- [replicator-instructions.docx](replicator-instructions.docx): Main instructions for replicators (process, expected outputs, and submission requirements).
- [replication-template.docx](replication-template.docx): Editable template for preparing replication documentation.
- [replication-example.pdf](replication-example.pdf): Example of a completed replication report.
- [PAP-example.pdf](PAP-example.pdf): Example of a pre-analysis plan (PAP).
- [special-issue-articles-pes.xlsx](special-issue-articles-pes.xlsx): Avaliable papers for replication in the special issue.
- [replication-metadata.xlsx](replication-metadata.xlsx): Metadata sheet for recording replication details and status.
